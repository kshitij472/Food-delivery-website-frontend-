# 🍔 Food Delivery Website (Frontend)

This is a frontend project for a food delivery website, built using **HTML, CSS, and JavaScript**.

## 🚀 Features
- Responsive homepage
- Navigation bar
- Food items display section
- Order button / cart UI (basic)
- Clean and modern UI design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📌 How to Run
Just open `index.html` in your browser — no server required.
